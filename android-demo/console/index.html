控制台负责生成和广播，Android App 负责渲染

1
启动控制台服务
python -u android-demo/server/a2ui_console_server.py --port 8787
2
把模拟器的 8787 端口反代到本机
adb reverse tcp:8787 tcp:8787
3
App 中点击「实时流」，地址填 http://127.0.0.1:8787/stream，再点「连接」。顶部出现 LIVE 即表示已就绪。
4
在控制台生成并推送，App 会按所选间隔逐条接收消息、边收边渲染。
5
车机 HMI 模式：左栏选「车机 HMI（1920×1200）」后生成走 demo/server/hmi-cli.ts，推送仍是同一条 SSE；模拟器画面由 HmiViewerActivity（WebView）承接。
python -u android-demo/tools/hmi_live_viewer.py
生成模式AI 模式调用 OpenAI 兼容接口；失败会自动回退本地规则。也可手动选「本地规则」离线生成。
部件范围Basic Catalog 子集：Text / Column / Row / Card / Button / TextField / CheckBox / Slider / Divider / Image / Icon / List。
图片Image 只渲染渐变占位和描述，不加载网络图片。
动作点击按钮只在本控制台提示 ACTION 和 context，不会回传到 App 或后端。
车机 HMI 场景选「车机 HMI」时由 hmi-cli.ts 确定性组装（原型 + 槽位 + 地图素材），中间预览只换成 16:10 横屏框，真实画面在 App 的 WebView 查看器里。
